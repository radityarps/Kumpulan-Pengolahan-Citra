Pelajaran 0001

Citra itu sebenarnya apa? (Spoiler: cuma tabel angka.)

Waktu baca: ±8 menit  ·  Tied to: AI Virtual Mouse · modul hand_tracker.py

1. Klaim utama pelajaran ini

Kalau ada satu hal yang harus kamu bisa jelaskan ke temanmu pakai kata-katamu sendiri, itu begini:

Sebuah citra digital (gambar) adalah sebuah tabel dua dimensi berisi angka, di mana setiap angka mewakili tingkat kecerahan atau warna di satu titik kecil yang disebut piksel (pixel = picture element).

Itu saja. Hampir semua hal di image processing — filter, threshold, edge detection, bahkan hand tracking — pada akhirnya adalah operasi matematika pada tabel angka ini. Kalau kamu paham ini, sisanya tinggal variasi.

2. Visualisasi: citra grayscale 4×4

Bayangkan citra grayscale (hitam-putih) terkecil yang masuk akal: 4×4 piksel. Tiap angka adalah 0 (hitam total) sampai 255 (putih total):

200  50  50  200
 50  50  50   50
 50  50  50   50
200  50  50  200

Kalau kamu gambar angka-angka itu sebagai kotak kecil (angka besar = putih, angka kecil = hitam), kamu dapat bentuk donat. Titik. Itu citra. Tidak lebih.

Citra berwarna (RGB) pada dasarnya tiga tabel ditumpuk: satu untuk Red, satu untuk Green, satu untuk Blue. Tiap titik punya tiga angka, mis. (255, 0, 0) = merah murni.

3. Ukuran citra & konsep "channel"

Citra webcam biasanya 640×480 piksel. Berarti ada:

  • 640 × 480 = 307.200 piksel untuk grayscale
  • 307.200 × 3 = 921.600 angka untuk RGB (3 channel)

OpenCV (library yang dipakai project ini) menyimpan citra sebagai NumPy array: sebuah tensor 3-dimensi dengan bentuk (height, width, channels).

import cv2
img = cv2.imread("foto.jpg")
print(img.shape)
# (480, 640, 3)   ← tinggi, lebar, channel
print(img[100, 200])
# [187 144  93]  ← piksel baris-100 kolom-200, channel BGR

Catatan: OpenCV baca warna dalam urutan BGR, bukan RGB. Ini jebakan klasik. Hapal: "OpenCV terbalik."

4. Kenapa ini penting untuk AI Virtual Mouse?

Project ini memproses frame demi frame dari webcam. Tiap frame adalah tabel angka seperti di atas. Alur besarnya:

  1. Webcam nangkap frame → tabel angka (shape (H, W, 3))
  2. MediaPipe Hand Landmarker deteksi 21 titik tangan → koordinat (x, y) di tabel itu
  3. Modul gesture_engine.py baca jarak antar-titik → "ini lagi pinch / open palm / etc."
  4. Modul cursor_mapping.py petakan koordinat tangan ke koordinat layar
  5. Sistem operasi gerakin kursor

Setiap langkah di atas memakan tabel angka dan menghasilkan tabel angka (atau keputusan). Tidak ada sihir. Langkah 1 sudah kamu pahami sekarang.

🧠 Quiz: 5 pertanyaan, jawab dari ingatan

Jangan balik baca. Tutup pelajaran sebentar, jawab di kertas, baru cek.

  1. Sebuah citra digital grayscale 100×100 piksel mengandung berapa angka?
  2. Sebutkan tiga channel warna pada citra RGB.
  3. Berapa nilai piksel untuk hitam total dan putih total pada grayscale 8-bit?
  4. OpenCV membaca warna dalam urutan apa? (RGB atau BGR?)
  5. Dalam alur AI Virtual Mouse, di langkah nomor berapa MediaPipe menerima "tabel angka" dari webcam?
Lihat jawaban
  1. 10.000 angka. 100 × 100 = 10.000 piksel grayscale.
  2. Red, Green, Blue. (Citra lain punya channel lain, mis. HSV = Hue, Saturation, Value.)
  3. 0 = hitam, 255 = putih. Kenapa 255? Karena 8-bit = 2⁸ = 256 nilai, mulai dari 0.
  4. BGR. "OpenCV terbalik."
  5. Langkah 1. Webcam menghasilkan frame (tabel angka), lalu MediaPipe mengolahnya di langkah 2.
Untuk tutor: waktu jelasin ke teman, pakai analogi "seperti Excel". Citra = spreadsheet. Tiap sel = satu angka = satu warna/kecerahan. Kalau mereka sudah pernah main Excel, sisanya jadi klik.
