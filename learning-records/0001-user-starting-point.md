# 0001 — User starting point and teaching posture

The user is a **beginner in both Python and image processing** (confirmed via intake questions, 2026-06-14). They are taking *Pengolahan Citra* (Image Processing) in Semester 6, and their stated mission is to learn deeply enough to **teach the material to friends and tutor them** — not just pass the course.

**Implications:**
- Lessons must build intuition before formalism. If the user can't *explain* it, they can't teach it.
- The AI Virtual Mouse project is the focal point; the 5 jobsheets are reference material, not the path.
- Code-walkthroughs of the existing project are the highest-leverage teaching tool — every concept lands on real code the user can point at.
- Indonesian for explanations, English for technical terms (matches the user's likely tutoring context).
- Storage strength matters more than fluency — quizzes and recall should appear in lessons, not just exposure.
